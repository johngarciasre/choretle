# Demo avatar credits

Photos used by `npm run seed` for the Brady Bunch demo family. All are
public-domain images of the cast from Wikimedia Commons, downloaded as 320px
thumbnails.

This directory is deliberately outside `public/`: the files are served only by
`GET /api/avatars/[file]`, which requires a signed-in member.
