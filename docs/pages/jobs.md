# Jobs

The Jobs page shows all active chores — tasks that have been assigned to family members and are waiting to be done or currently in progress.

## What You See

- A grid of job cards, each showing:
  - The chore name and description.
  - Points value.
  - Status badge (Todo, Doing, Under Review, Done).
  - Assignee name (if assigned).

## How to Use

### Viewing a Job Detail

1. Click on any job card from the grid.
2. On the detail page you will see:
   - **Job Details** — Name, description, points, verification status, and subtask progress.
   - **Subtask Progress** — If the job has subtasks, a checklist with a progress bar.
   - **Status Controls** — Buttons to advance the job through its workflow.
   - **History** — A log of all status changes and actions on this job.
   - **Comments** — A thread for leaving notes about the job.

### Changing a Job's Status

The status buttons change depending on the current state:

| Current Status | Available Actions          |
|---------------|---------------------------|
| Todo          | Start → Doing             |
| Doing         | Done / Submit for Review  |
| Under Review  | Mark Complete / Request Rework |
| Done          | (completed — no actions)  |

### Completing Subtasks

- If a job has subtasks, check each one off individually.
- When all subtasks are checked, the progress bar fills completely and you can mark the entire job as Done.

### Earning Points

Points are automatically awarded when a job reaches the **Done** status. The number of points matches the task's configured point value.
