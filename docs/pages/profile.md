# User Profile

The User Profile page shows an individual family member's stats, achievements, and chore completion history.

## What You See

- **Profile Hero** — A gradient banner with the user's avatar, name, role, total points, and current streak.
- **Stats Grid** — Four summary cards:
  - Total Points
  - Jobs Done
  - Average Points per Job
  - Best Streak (longest consecutive streak)
- **Weekly Trend** — A comparison of this week's points vs. last week's (shown as up or down).
- **7-Day Activity Chart** — A bar chart showing daily point totals for the past week.
- **Categories** — A breakdown of points by category with progress bars.
- **Points History** — A timeline of recent job completions (up to 8 shown).
- **Badges / Achievements** — Earned and unearned achievement badges with descriptions.

## How to Use

### Viewing Your Profile

- Click **Your Profile** from the Dashboard, or navigate directly to `/profile/[your-user-id]` via the profile dropdown in the NavBar.

### Understanding Badges

| Badge           | Description        | Requirement    |
|-----------------|--------------------|----------------|
| First Task      | Complete your first task       | ≥ 1 job done   |
| Hard Worker     | Be a diligent worker           | ≥ 5 jobs done  |
| Streak Starter  | Build momentum                 | 3-day streak   |
| Point Master    | Accumulate points                | ≥ 100 pts      |
| Streak Pro      | Show consistency               | 7-day streak   |
| Champion        | Achieve mastery                  | ≥ 500 pts      |

Badges that are earned display their icon; unearned badges show a placeholder.
