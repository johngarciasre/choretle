# Tasks

The Tasks page is where you browse, create, edit, and organize all available chores in your family.

## What You See

- A grid of task cards showing each chore's name, description, points value, and assigned tags.
- A tag filter bar at the top to narrow down tasks by category.
- A floating **+** button to create a new task.

## How to Use

### Creating a Task

1. Click the **+** floating button (bottom-right corner).
2. Fill in the task form:
   - **Name** — e.g., "Clean the kitchen"
   - **Description** — Optional details about what the chore entails.
   - **Points** — How many points a child earns for completing this task.
   - **Tags** — Click one or more tags to categorize the task (e.e., "Kitchen", "Cleaning").
3. Click **Create Task**.

### Editing a Task

1. Hover over any task card to reveal the edit and delete icons in the top-right corner.
2. Click the **pencil icon** to open the edit modal.
3. Modify any field (name, description, points, tags).
4. Click **Update Task**.

### Deleting a Task

1. Hover over the task card.
2. Click the **trash icon**.
3. Confirm the deletion in the popup dialog.

### Filtering by Tag

- Click any tag pill in the filter bar to toggle it on or off. Tasks matching all selected tags will be displayed.
